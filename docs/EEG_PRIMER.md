# EEG 배경지식 — 바이브코딩 전에 알아야 할 것

Claude Code 에게 일을 시킬 때 아래 개념을 알고 있어야 "그럴듯하지만 틀린 코드"를 걸러낼 수 있다.

## 1. EEG 가 재는 것
- 두피 아래 수많은 피질 뉴런의 시냅스 후 전위가 **동시에** 움직일 때 생기는 전압 변화(µV 단위). 개별 뉴런이나 깊은 구조(편도체·해마)는 직접 못 본다.
- 그래서 EEG 는 '어디서'보다 **'언제, 어떤 리듬으로'**에 강하다. 4채널 Muse 는 더더욱 그렇다.

## 2. Muse 2 하드웨어
| 항목 | 값 | 함의 |
|---|---|---|
| 채널 | TP9(왼쪽 귀 뒤), AF7(왼쪽 이마), AF8(오른쪽 이마), TP10(오른쪽 귀 뒤) | 정중선(Fz, Cz, Pz)·후두(O1, O2) 없음 |
| 기준전극 | Fpz(이마 중앙) | 이마 채널은 기준과 가까워 신호가 작고 눈 움직임 영향 큼 |
| 샘플링 | 256 Hz | 분석 가능 상한 128 Hz, 실제론 40 Hz 이하만 신뢰 |
| 전극 | 건식 | 접촉 저항 큼 → 잡음 많음, 착용 상태가 데이터 질을 좌우 |
| 추가 | Right AUX(외부 전극 단자) | 연결 안 하면 쓰레기 신호 → 반드시 제외 |

## 3. 주파수 대역 — '정답표'가 아니라 '경향'
| 대역 | Hz | 잘 알려진 경향 | Muse 에서 주의 |
|---|---|---|---|
| 델타 | 1–4 | 깊은 수면 | 깨어 있을 때 큰 델타는 대개 눈 깜빡임·움직임 |
| 세타 | 4–8 | 작업기억 부하(전두 정중선), 졸림 | AF 채널 세타 급등 = 먼저 깜빡임 의심 |
| 알파 | 8–13 | 눈 감기·이완 시↑, 시각 주의·정신 작업 시↓ | TP 채널에서 잘 보임. **가장 신뢰할 수 있는 효과** |
| 베타 | 13–30 | 각성·능동적 사고 | 턱 힘·찡그림(근전도)이 섞이기 쉬움 |
| 감마 | 30+ | 고차 처리 보고가 있으나 두피 EEG 에선 근전도와 구분 어려움 | **해석 금지** |

> 이전에 받은 표(뇌파_후각_관련_이론)의 "알파=안정, 베타=집중"은 출발점으로는 맞지만, 실제 분석은 항상 **본인 휴식 대비 변화**로 본다. 절대값 '베타가 높으니 집중'은 틀릴 수 있다(사람·착용 상태마다 절대값이 다름).

## 4. 스펙트럼 분석 핵심 개념
- **PSD(전력 스펙트럼 밀도)**: 주파수별 세기. 단위 µV²/Hz. Welch 방법 = 짧은 구간 FFT 를 여러 번 해서 평균.
- **창 길이 ↔ 주파수 해상도**: 해상도 ≈ 1/창 길이. 2초 창 → 0.5 Hz, 4초 → 0.25 Hz. IAF 처럼 정밀한 값은 긴 창(휴식 구간 전체), 시간 변화는 짧은 창.
- **절대 vs 상대 파워**: 절대는 접촉 상태에 민감, 상대(대역/전체)는 덜 민감.
- **로그**: 파워·비율은 오른쪽으로 꼬리가 긴 분포 → log 후 평균/z.
- **z 점수**: (현재 − 기준 평균) / 기준 SD. "평소보다 얼마나 다른가"를 사람 간 공통 척도로.

## 5. 잡음(아티팩트) 도감
| 잡음 | 모양 | 어디서 | 대응 |
|---|---|---|---|
| 눈 깜빡임 | 0.2–0.4초 큰 둔한 파형(수백 µV) | AF7/AF8 | ptp 임계로 창 제외 |
| 눈 굴리기 | 느린 큰 드리프트 | AF7/AF8 | 고역통과 1 Hz + 제외 |
| 턱·이 악물기 | 빠르고 거친 고주파 | TP9/TP10 | 베타·감마 급등 → 제외, 측정 안내 |
| 움직임·센서 들뜸 | 급격한 계단·포화 | 전 채널 | 제외 |
| 60 Hz 전원 | 정확히 60 Hz 피크 | 전 채널 | 노치 필터 |
| 블루투스 끊김 | 샘플 누락(타임스탬프 간격) | – | `meta.n_gaps` 확인 |

### 기존 결과물(muse2 사용설명서 3번)에 대한 진단
- **세타 그래프의 1500–2000 스파이크**: 대부분 눈 깜빡임/움직임 잡음일 가능성이 높다. 잡음 창 제외 후 다시 보면 사라질 것.
- **PSD 세로축 120–160 dB**: BlueMuse 데이터(µV)를 MNE(V 기대)에 그대로 넣어 10¹² 배(=120 dB) 부풀려진 것. `load_xdf` 에서 ×1e-6 으로 해결.
- **`raw_filtered.get_data()`**: picks 를 안 주면 Right AUX(misc)까지 섞일 수 있다 → `picks="eeg"`.
- **topomap**: 점 4개를 보간한 그림이라 "왼쪽 뒤가 자극됐다" 같은 해석은 근거가 약하다 → 채널별 막대/좌우 비대칭 지표로 대체.
- **마커 없음**: 언제 문제를 풀었는지 기록이 없어 '수학 문제 구간 vs 휴식 구간' 비교를 손으로 해야 했다 → LSL 마커로 자동화.

## 6. 바이브코딩 함정 체크리스트 (Claude 가 자주 틀리는 것)
- [ ] 창마다 따로 필터링하고 있지 않은가 (연속 신호에 먼저!)
- [ ] µV/V 단위가 섞이지 않았는가
- [ ] 사람마다 다른 절대값을 그대로 비교하지 않는가 (z 점수 사용?)
- [ ] 겹치는 창 수천 개로 t-test 해서 "유의함"이라고 쓰지 않았는가
- [ ] 같은 사람 데이터가 학습/테스트에 섞이지 않았는가 (교차 피험자 평가는 사람 단위로 분할)
- [ ] 블록 순서 효과(피로)를 난이도 효과로 착각하지 않았는가
- [ ] 진단적 표현이 결과 문구에 들어가지 않았는가

## 7. 아이디어 뱅크 (3번·4번 확장)
| 아이디어 | 무엇을 보여 주나 | 난이도 | 비고 |
|---|---|---|---|
| **Dual N-back** (위치 + 글자 소리) | 시공간 vs 언어성 작업기억 분리 점수 | 중 | 2번 담당과 협의, Jaeggi 2008 |
| **적응형 N-back 훈련** | 정확도 + workload z 로 N 자동 조절 → "뇌에 맞춘 훈련" | 중 | 4번(훈련)과 바로 연결 |
| **PVT(정신운동 각성 과제)** 5분 | 지속 주의 + lapse, 피로에 매우 민감 | 하 | 지속 집중 시간의 행동 근거 |
| 암산 과제 vs 눈감기 | 기존 실험 재현, 알파↓ 대비 명확 | 하 | 시연 오프닝용 |
| **실시간 집중 게이지** | 화면 막대가 집중하면 차오름 | 중 | `scripts/live_monitor.py` 발전 |
| 알파 뉴로피드백(이완 훈련) | 눈 감고 알파↑ 시 소리 보상 | 중 | 훈련 모듈 후보 |
| 개인 보정 분류기 | 5분 보정 후 '집중 확률' 실시간 | 중 | 교차 피험자보다 현실적 |
| P300 (오드볼/N-back 타깃) | 타깃 자극 후 300 ms 양전위, 부하↑ 시 감소 | 상 | Muse 로 가능 보고(Krigolson 2017), 시행 수 많이 필요 |
| 비주기(1/f) 기울기 | 휴식 뇌파의 '배경 잡음' 기울기 추세 | 중 | specparam 라이브러리 |
| 세션 간 변화 대시보드 | 주차별 IAF·집중·지속시간 추세 | 하 | 5번(변화 추적) |
