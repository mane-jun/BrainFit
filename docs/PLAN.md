## 1. 현실 점검: Muse 2 로 '되는 것'과 '안 되는 것'

| 구분 | 내용 |
|---|---|
| ✅ 확실히 됨 | 눈 감으면 알파↑(알파 반응성), 개인 알파 피크(IAF), 휴식 vs 과제 대역 파워 차이, 시간 경과에 따른 피로성 변화 추세, 근전도·깜빡임 같은 잡음 검출 |
| ⚠️ 조건부로 됨 | N-back 난이도에 따른 세타↑·알파↓ (Fz 가 없고 AF 채널이 깜빡임에 취약 → 사람마다 안 보일 수 있음), 개인 맞춤 집중/이완 분류기(본인 데이터로 5분 보정 시) |
| ❌ 안 됨(주장 금지) | 뇌파만으로 '언어 능력 82점', '시공간 능력 55점' 측정, 진단(ADHD·치매 등), 4채널 topomap 으로 뇌 부위 해석, 감마파 해석, 다른 사람 데이터로 학습한 모델을 처음 보는 사람에게 그대로 적용 |

그래서 방향을 이렇게 잡는다:

> **능력 점수는 과제 수행 성과(정확도·d′·반응시간)에서, 뇌파는 '그 순간의 상태(몰입·부하·피로)'와 '본인 기준 대비 변화'를 보여 준다.**
> 둘을 같은 시간축에 묶어 주는 것이 LSL 마커이고, 이것이 이 프로젝트의 기술적 핵심이다.

이렇게 쓰면 심사위원이 "4채널로 언어 능력을 어떻게 재요?"라고 물어도 정확히 답할 수 있다: "언어 점수는 과제 성과로 재고, 뇌파는 그 과제를 할 때 얼마나 몰입했고 언제 지쳤는지를 보여 줍니다."

## 2. 세부내용 1번 — 사용자 기본 뇌파 측정: 구체화

### 2-1. 측정
- 눈 뜬 휴식(EO) 60–120초 → 눈 감은 휴식(EC) 60–120초 (docs/PROTOCOL.md)
- 마커로 구간을 정확히 표시 (`rest_eo_start/end`, `rest_ec_start/end`)

### 2-2. 추출하는 특징 (`brainfit/baseline.py`)
| 특징 | 사용자에게 보여 줄 말 | 내부 용도 |
|---|---|---|
| 알파 반응성 EC/EO | "눈을 감으면 이완 리듬이 평소의 ○배로 커집니다" | 측정 품질 확인 + 각성 상태 |
| IAF | "당신의 고유 알파 리듬은 ○ Hz" | 개인 맞춤 대역, 세션 간 안정성 |
| 상대 파워 θ/α/β | 휴식 시 리듬 구성 그래프 | 상태 비교의 기준 |
| EO 지표 평균·SD | (표시 안 함) | 3번의 모든 z 점수 기준 |

### 2-3. 공개 데이터와 비교 (+a)
1. **같은 기기 데이터 우선**: Bird et al.(2018) Muse 정신상태 데이터(이완/중립/집중, 5명, 각 1분, Kaggle) → "이완/집중 상태 분류" 데모 모델. 단, 5명 데이터라 처음 보는 사람에겐 성능이 낮다는 점을 **발표에서 먼저 말한다**.
2. **집단 참고값**: IAF 같은 지표는 문헌값(성인 약 10 Hz)을 기준으로 "참고 위치"만 표시.
3. **(확장) 대규모 휴식 데이터**: MPI-LEMON 의 EO/EC 데이터에서 Muse 와 같은/가까운 위치 채널만 뽑아 IAF·알파 반응성 분포를 만들고 백분위로 표시. 데이터가 커서(수십 GB) 시간 여유가 있을 때만.
4. **2회차부터는 본인 기준**: `BaselineStore` 가 '나의 평소'를 만든다. 이것이 기획안의 "이후 측정부터는 사용자 자신의 이전 데이터를 기준선으로" 를 구현한 부분.

### 2-4. "유형별 학습 모델"의 현실적 버전
- 다른 사람 데이터로 학습한 모델(교차 피험자)은 EEG 에서 성능이 크게 떨어진다.
- 대신 **개인 보정 모델**: 첫 세션의 EO 휴식 vs 2·3-back 블록 창을 라벨로 로지스틱 회귀/랜덤포레스트를 학습 → 이후 세션에서 '집중 확률'을 실시간 표시. 5분 데이터면 충분하고, 시연에서 "당신 뇌에 맞춘 모델"이라는 메시지가 된다.
- 공개 데이터 모델은 "사전학습 → 개인 데이터로 미세조정" 서사로 쓸 수 있다(시간 여유 시).

## 3. 세부내용 3번 — 집중력 및 인지 상태 분석: 구체화

### 3-1. 데이터 결합 구조
```
[Grid N-back 앱] --LSL 마커(stim/trial/block)--┐
                                              ├─> LabRecorder → session.xdf → load_xdf()
[Muse 2 → BlueMuse] --LSL EEG(256Hz, µV)------┘
                                                   ↓
   창(2초)별 θ/α/β ── EO 기준 z ── 블록·시행 라벨 ── 행동 지표(d′, RT)
```

### 3-2. 질문별 산출물
| 질문 | 산출물(그림) | 시연 멘트 예 |
|---|---|---|
| 어느 문제에서 집중이 오래 유지되나 | `05_blocks.png` 블록별 집중 z·유지율 | "2-back 에서 몰입이 가장 오래 유지됐어요" |
| 어느 과제에서 빨리 떨어지나 | 블록 내 분당 기울기 | "3-back 은 시작 30초 후부터 몰입이 급감" |
| 피로 누적 변화 | `06_fatigue.png` + 사전/사후 눈감기 비교 | "15분 후 이완 리듬 +26%, 정확도 −10%p" |
| 평소 대비 | `vs_usual` (JSON, 앱 카드) | "오늘 집중은 평소보다 0.8 SD 낮아요" |
| 지속 집중 시간 | `04_engagement.png` | "지속 집중 약 5.4분" |
| Brain Profile | `07_profile.png` 레이더 | 집중력 84 / 작업기억 52 … |

### 3-3. Grid N-back 을 쓰는 이유
- 작업기억 연구의 표준 과제(Owen et al., 2005 메타분석), 난이도(N)를 숫자로 조절 → '부하 ↔ 뇌파' 관계를 보여 주기 쉽다.
- 3×3 격자 = **시공간 작업기억**. 같은 틀에 글자 소리를 더하면 Dual N-back(Jaeggi et al., 2008) → **언어성 작업기억** 점수도 얻는다 → 프로필의 '시공간'과 '언어'를 같은 과제 틀에서 분리 측정 가능(2번 담당과 협의 포인트).
- 0-back(가운데 칸이면 누르기)을 대조 조건으로 넣으면 '기억 부담 없는 주의'와 비교 가능.
- 훈련(4번)으로도 그대로 쓸 수 있다: 정확도·workload z 에 따라 N 을 올리고 내리는 **뇌파 기반 적응형 난이도**.

### 3-4. 검증 기준 (파일럿 3–5명)
| 확인 | 성공 기준 | 실패 시 대응 |
|---|---|---|
| 알파 반응성 | 전원 EC/EO > 1.3 | 센서 접촉 개선, TP 위치 재착용 |
| 행동 난이도 효과 | d′: 1-back > 2-back > 3-back (대부분) | 시행 수 늘리기, 자극 시간 조정 |
| 뇌파 부하 효과 | workload z: 3-back > 1-back (과반) | 안 보이면 '행동 중심 + 뇌파 탐색적' 으로 발표 프레임 조정 |
| 품질 | 사용 가능 창 ≥ 60% | 측정 환경 체크리스트 강화 |

## 6. 기획안(10/7 마감) '세부 내용'에 바로 쓸 문장 초안
- 1번: "Muse 2(4채널 EEG)로 눈 뜬/감은 휴식 뇌파를 측정해 개인 알파 피크 주파수(IAF)와 알파 반응성을 추출한다. 개인차가 큰 EEG 특성을 고려해 모든 상태 지표는 본인 휴식 구간 대비 z 점수로 표준화하고, 2회차부터는 누적된 본인 기록을 기준선으로 사용한다. 공개 데이터셋(Muse 기반 정신상태 데이터 등)은 초기 참고 분포와 상태 분류 모델의 사전학습에 활용한다."
- 3번: "인지 과제(Grid N-back 등) 수행 중 사건 마커를 LSL 로 뇌파와 동기화 기록하여, 과제·시행 단위로 몰입 지수 β/(α+θ), 작업부하 지수 θ/α, 피로 지수 (θ+α)/β 를 산출한다. 이를 정답률·d′·반응시간과 결합해 과제별 집중 유지 시간, 집중 감소 속도, 피로 누적 추세를 분석하고 Brain Profile 로 시각화한다. 영역별 능력 점수는 과제 수행 성과로, 뇌파는 수행 중 상태 정보로 사용해 해석의 타당성을 확보한다."
