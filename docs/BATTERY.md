# BrainFit Cognitive Battery v1 — 상세 프로토콜

> 구현: `tasks/battery.py` (과제), `brainfit/config.py::BATTERY_MODES` (파라미터), `brainfit/profile.py` (점수), `brainfit/erp.py` (P300)
> 이 문서의 숫자를 바꾸면 config 와 같은 PR 에서 함께 바꾼다.

## 0. 설계 원칙
1. **측정 → 분석 → 훈련 → 재측정**이 한 번에 돌아가는 것이 프로토타입의 핵심이다.
2. 능력 점수 = 행동(정답률·d′·반응시간). 뇌파 = 상태(몰입·부하·피로) + ERP(P300). 둘을 섞어 말하지 않는다.
3. 노년층이 1차 대상이므로 **노년층 모드**를 따로 둔다(느린 속도, 큰 자극, 연습 충분).
4. 모든 과제는 LSL 마커(`docs/MARKERS.md`)로 EEG 와 동기화된다.
5. 재검사 때는 `--seed` 를 바꿔 **다른 자극 순서**를 쓴다(연습효과 완화).

## 2. 과제별 상세

### 2-1. PVT (Psychomotor Vigilance Task) — 노년층 모드
| 항목 | 값 | 이유 |
|---|---|---|
| 자극 | 화면 중앙 초록 원 | 단순 반응 |
| 자극 간 간격 | 2–6 s 무작위 | 예측 반응 방지 (표준 PVT 2–10 s 를 단축) |
| 응답 제한 | 1.5 s | 노년층 고려 |
| 측정값 | 반응시간 중앙값, **lapse**(RT > 500 ms 또는 무응답), false start(자극 전 누름) | Basner & Dinges, 2011 |
| EEG | 과제 중 engagement, 시간에 따른 fatigue | 각성 저하 감지 |

### 2-2. Go/No-Go — 반응속도 · 억제조절
| 항목 | standard | senior |
|---|---|---|
| 자극 | Go = 초록 원 / No-Go = 빨간 사각형 (**색 + 모양** 둘 다 달라서 색각 이상도 구분 가능) | 같음, 1.4배 크게 |
| 비율 | Go 75% / No-Go 25% | 같음 |
| 제약 | No-Go 앞에 Go 최소 2개, No-Go 연속 금지 → '누르려는 습관'을 만든 뒤 억제를 요구 | 같음 |
| 자극 제시 | 300 ms | 500 ms |
| 응답 창 | 자극 시작부터 800 ms | 1200 ms |
| 시행 간 간격 | 700–1100 ms 지터 | 1000–1400 ms |
| 시행 수 | 100 (Go 75 / No-Go 25) | 80 (60 / 20) |
| 무효 처리 | RT < 150 ms = 예측 반응 | 같음 |
| 측정값 | Go RT 중앙값, **RT 변동계수(CV = SD/평균)**, 오반응률(No-Go 에서 누름 = commission), 누락률(omission), d′ | |
| EEG | 블록 engagement z. (확장) No-Go 시행 후 200–500 ms 전두 세타 증가 — AF 채널이라 탐색적 | |

### 2-3. Grid N-back — 작업기억(시공간)
| 항목 | standard | senior |
|---|---|---|
| 자극 | 3×3 격자 한 칸 점등 | 같음 |
| 블록 순서 | 1 → 2 → 2 → 1 (ABBA: 난이도 효과와 피로 효과 분리) | 0 → 1 → 2 → 1 |
| 시행 | 블록당 20 + N | 16 + N |
| 자극 제시 / 시행 길이 | 500 ms / 2.5 s | 800 ms / 3.0 s |
| 타깃 비율 | 약 30% | 같음 |
| 0-back 규칙 | 가운데 칸이 켜지면 누르기 (기억 부담 없는 대조 조건) | |
| 측정값 | 블록별 d′, 정확도, RT | |
| EEG | **workload z = log(θ_AF / α_TP)** 의 2-back − 1-back 차이(부하 반응), engagement | Gevins 1997 |

### 2-4. Visual Oddball — 주의 정확성 + P300
| 항목 | standard | senior |
|---|---|---|
| 자극 | 표준 = 회색 원(80%) / 타깃 = 노란 삼각형(20%) | 같음, 크게 |
| 제약 | 타깃 앞에 표준 최소 2개, 타깃 연속 금지 | |
| 자극 제시 | 250 ms | 400 ms |
| 자극 간 간격 | 1000–1300 ms 지터 | 1100–1400 ms |
| 시행 수 | 180 (타깃 36) | 150 (타깃 30) |
| 반응 | 타깃에만 SPACE | |
| 측정값 | 적중률, 오경보율, d′, RT | |
| EEG | **P300**: TP9·TP10 평균, 0.5–15 Hz 필터, −200~800 ms 에포크, 자극 전 기준선 보정, ±100 µV 초과 에포크 제외 → 타깃−표준 차이파의 **250–500 ms 평균 진폭**과 피크 잠복기 | Krigolson 2017 |
| 품질 기준 | 깨끗한 타깃 에포크 ≥ 25개일 때만 점수화, 아니면 '측정 불충분' | |

> P300 주의: 블루투스 전송 지연 때문에 **절대 잠복기(ms)를 임상 논문 값(예: 알츠하이머군 잠복기 지연)과 비교하면 안 된다.** 같은 장비·프로그램으로 잰 본인 이전 기록과의 변화만 본다. 한 세션의 잠복기는 수십 ms 흔들릴 수 있으므로(가짜 데이터에서도 확인됨) 진폭(구간 평균)을 주 지표로 쓴다.

## 3. 세션 공통 뇌파 지표 (1번·3번)
| 구간 | 지표 | 용도 |
|---|---|---|
| EO/EC | IAF, 알파 반응성(EC/EO), 상대 파워 | 1번 기준선, 측정 품질 확인 |
| 모든 과제 | engagement·workload·fatigue 의 EO 대비 z | 3번: 과제별 몰입, 감소 기울기, 지속 집중 |
| 사전 vs 사후 EC | 알파·세타 변화율 | 3번: 피로 누적 |
| 전체 | 사용 가능 창 비율 | 품질 게이트 (60% 미만이면 재측정 권고) |

## 4. 점수 계산 — 육각형 Brain Profile

| 축 | 원지표 | 방향 | 계산 |
|---|---|---|---|
| 반응속도 | Go RT 중앙값 | 낮을수록 좋음 | z = −(RT − μ)/σ |
| 억제조절 | No-Go 오반응률 | 낮을수록 좋음 | z = −(rate − μ)/σ |
| 작업기억 | 2-back d′ | 높을수록 좋음 | z = (d′ − μ)/σ |
| 주의 정확성 | Oddball d′ | 높을수록 좋음 | |
| 집중 유지 | ½·(1 − Go RT CV/0.5) + ½·(휴식보다 몰입이 높은 과제 창 비율) | 높을수록 좋음 | 행동 + 뇌파 |
| 뇌 반응(P300) | P300 구간 평균 진폭(µV) | 높을수록 좋음 | 품질 통과 시에만 |

- **점수 = round(100 × Φ(z))** → 연령대 평균이면 50, +1 SD 면 84, −1 SD 면 16.
- **종합 인지 수행** = 행동 4축(반응속도·억제조절·작업기억·주의 정확성) 평균. 뇌파 축은 종합에 넣지 않는다(해석 혼동 방지).
- μ, σ (`HEX_REFERENCE`) 는 **현재 임시값**이다. 연령대별 파일럿 최소 5명 이후 실측 평균·SD 로 교체하고, 그 전까지 화면에 "임시 기준" 표시.
- 기존 기획안 예시의 '언어 능력', '시공간 능력', '계산 능력'은 이 배터리에 없다 → 2번 담당의 확장 과제(아래 6절)로 추가하거나, 기획안 예시를 위 6축으로 바꾼다.

### 지속 집중 시간에 대한 주의
15분 배터리에서는 "18분 지속 집중" 같은 값이 나올 수 없다(측정 시간보다 길 수 없음). 배터리에서는 **과제 중 집중 유지율**을 보고, 긴 지속 집중 시간은 **5번 집중 모드(공부 30–60분 측정)** 에서 잰다.

## 5. 변화 추적과 재검사
- 주기: 노년층 주 1회 또는 격주, 같은 시간대(오전 권장), 같은 모드.
- 자극 세트: 매 회 `--seed` 변경 → 순서가 달라져 암기 효과 감소. 처음 2회는 '적응 기간'으로 표시(연습효과가 가장 큼).
- **의미 있는 변화 판단 — 신뢰 변화 지수(RCI, Jacobson & Truax, 1991)**
  RCI = (이번 − 이전) / (SD × √(2 × (1 − r)))
  r = 검사-재검사 신뢰도(파일럿으로 추정, 그 전엔 0.7 가정). |RCI| > 1.96 일 때만 "의미 있게 변했어요"라고 말한다. 그 이하는 "변동 범위 안".

## 6. 훈련 추천 (4번 연결, `brainfit/recommend.py`)
1. 가장 낮은 축 2개를 추천. 본인 평균보다 10점 이상 떨어진 축은 우선.
2. **적응형 N-back 규칙**: 블록 정확도 ≥ 85% 이고 workload z < 1.5 → N+1 / 정확도 < 60% 이거나 (workload z > 2 이고 정확도 < 75%) → N−1 / 나머지 유지. "정확해도 뇌가 과부하면 올리지 않는다"가 EEG 를 쓰는 이유.
3. Go/No-Go 훈련: 오반응 < 10% 면 시행 간격 −100 ms, > 30% 면 +100 ms.
4. 'AI' 는 규칙으로 시작 → 데이터가 쌓이면 (사용자, 훈련, 다음 점수 변화)로 밴딧/회귀 모델로 교체.

### 2번 담당과 협의할 확장 과제
| 기획안 영역 | 후보 과제 | 측정값 |
|---|---|---|
| 언어 | 글자 N-back(소리 또는 글자), Stroop(색 단어) | d′, 간섭 효과(불일치 RT − 일치 RT) |
| 시공간 | Grid N-back(이미 포함), Corsi 블록 | 기억 폭 |

새 과제는 `trial` 마커에 target/resp/correct/rt 만 맞추면 분석 파이프라인에 바로 들어온다.

## 7. 5번 집중력 경쟁 기능 설계 메모
- 사람마다 뇌파 절대값이 달라서 **절대 점수로 경쟁하면 불공정**하다 → "본인 휴식 대비 몰입 상태였던 시간", "지난주 대비 향상률"로 경쟁.
- **신호 품질 게이트** = 부정행위 방지: 착용이 불량하거나 잡음 구간은 집중 시간에서 제외.
- 표현은 "정확한 집중 시간"이 아니라 "뇌파 기반 집중 상태 추정 시간".
