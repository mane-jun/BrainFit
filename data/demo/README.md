# data/demo — 라이브 화면 재생용 뇌파

`scripts/import_recording.py` 로 만든 `.npz` 파일. 라이브 화면에서 입력을 '녹화 재생'으로 고르고 경로를 넣으면
실제 기기 없이 실제(또는 가짜) 뇌파로 화면을 개발·시연할 수 있다.

| 파일 | 내용 | 공개 가능 |
|---|---|---|
| `synthetic_demo.npz` | 가짜 데이터(demo 배터리 구조) | ✅ |
| (예) `p01_session1.npz` | 실측 데이터 | 본인 서면 동의 + 실명 없는 ID 일 때만. 아니면 커밋 금지 |

실측 파일은 기기 MAC·PC 이름 같은 메타데이터를 제거하고 저장된다. 그래도 뇌파는 개인 데이터다.
